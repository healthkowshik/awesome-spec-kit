## Spec-Kit Ecosystem

- [cline-spec-kit-workflows](https://github.com/JRedeker/cline-spec-kit-workflows) - Comprehensive workflow files for spec-driven development in the Cline AI coding agent.
- [iac-spec-kit](https://github.com/IBM/iac-spec-kit) - Domain-specific implementation of spec-driven development optimized for infrastructure-as-code workflows with Terraform, Pulumi, and Ansible.
- [lite-kits](https://github.com/tmorgan181/lite-kits) - Lightweight add-ons for Spec Kit including project orientation, Git commands, and multi-agent collaboration features.
- [piv-speckit](https://github.com/galando/piv-speckit) - Combines Prime-Implement-Validate methodology with Spec Kit for structured specifications and strict test-driven development.
- [sdd-skill](https://github.com/SpillwaveSolutions/sdd-skill) - Claude Code skill for guiding users through the full Spec Kit workflow and spec-driven development methodology.
- [Spec Kit](https://github.com/github/spec-kit) - Open-source toolkit for spec-driven development providing templates, a CLI, and structured workflows for AI-assisted engineering.
- [Spec Kit Discussions](https://github.com/github/spec-kit/discussions) - Official community forum for methodology discussion, workflow sharing, and maintainer support.
- [Spec Kit Documentation](https://github.github.com/spec-kit/) - Official documentation portal covering installation, quickstart, development phases, and the full SDD methodology.
- [spec-kit-antigravity](https://github.com/waveupHQ/spec-kit-antigravity) - Agent-first specification and orchestration kit adapting Spec Kit for Google Antigravity and Gemini.
- [spec-kit-brownfield-extensions](https://github.com/wcpaxx/spec-kit-brownfield-extensions) - Bootstrap extension that brings existing codebases into the spec-driven development workflow.
- [spec-kit-command-cursor](https://github.com/madebyaris/spec-kit-command-cursor) - Ports the spec-driven development toolkit to Cursor IDE with /specify, /plan, and /tasks commands.
- [spec-kit-extensions](https://github.com/MartyBonacci/spec-kit-extensions) - Five workflows extending Spec Kit to cover bugfix, modification, refactor, hotfix, and deprecation scenarios.
- [spec-kit-jira](https://github.com/mbachorik/spec-kit-jira) - Bridges spec-driven development workflows with Jira project management for enterprise teams.
- [spec-kit-mcp](https://github.com/lsendel/spec-kit-mcp) - MCP server enabling AI assistants to use the spec-driven development methodology via the Model Context Protocol.
- [spec-kit-plus](https://github.com/panaversity/spec-kit-plus) - Extended fork with patterns and templates for building scalable multi-agent AI systems.
- [spec-kit-v-model](https://github.com/leocamello/spec-kit-v-model) - V-Model extension enforcing paired development and test specifications with regulatory-grade traceability.
- [spec-kit Topic](https://github.com/topics/spec-kit) - Discovery hub aggregating public repositories tagged with the spec-kit topic on GitHub.
- [spec-kitty](https://github.com/Priivacy-ai/spec-kitty) - Enhanced spec-driven development adding a Kanban dashboard, Git worktrees, auto-merge, and multi-agent support.
- [speckit-agent-skills](https://github.com/dceoy/speckit-agent-skills) - Agent skills extension pack providing additional capabilities for AI coding assistants using Spec Kit.
- [speckit.org](https://speckit.org/) - Official landing page with overview, features, getting started instructions, and community links.
- [SpecLang](https://githubnext.com/projects/speclang/) - GitHub Next research prototype treating natural-language specifications as primary source of truth, the conceptual predecessor to Spec Kit (no longer maintained).

- [Implement Spec-Driven Development Using GitHub Spec Kit](https://learn.microsoft.com/en-us/training/modules/spec-driven-development-github-spec-kit-enterprise-developers/) - Advanced Microsoft Learn training module for enterprise brownfield scenarios with Copilot, covering constitution files and team scaling.
- [LinkedIn Learning: SDD with GitHub Spec Kit](https://github.com/LinkedInLearning/spec-driven-development-with-github-spec-kit-4641001) - Companion repository for the video course covering constitution creation, spec generation, plan development, and implementation.

- [Redreamality: Spec Kit Deep Dive](https://redreamality.com/garden/notes/github-spec-kit-guide/) - Comprehensive deep-dive covering Spec Kit internal mechanisms, operational workflows, and architectural philosophy for enterprise teams.
- [Spec-Driven Development Tutorial Using GitHub Spec Kit](https://www.scalablepath.com/machine-learning/spec-driven-development-workflow) - Step-by-step tutorial building a trip-planner AI agent demonstrating the full specify-plan-tasks-implement workflow.
- [Spec-Driven Development with Spec Kit and Kilo Code](https://blog.kilo.ai/p/spec-driven-development-what-it-is) - Getting-started guide for using spec-driven development with the Kilo Code AI assistant, covering slash commands and project initialization.
- [Spec-Kit Walkthrough](https://matsen.fredhutch.org/general/2026/02/10/spec-kit-walkthrough.html) - Computational biologist's walkthrough applying spec-driven development to a real bioinformatics pipeline.
- [speckit-tutorial](https://github.com/kkawailab/speckit-tutorial) - Progressive Japanese-language tutorials covering ToDo app, REST API, and microservices projects with increasing complexity.

## Articles

- [A Look at Spec Kit](https://tessl.io/blog/a-look-at-spec-kit-githubs-spec-driven-software-development-toolkit/) - Independent analysis placing Spec Kit in the context of SpecLang and AWS Kiro, examining the broader spec-driven development landscape.
- [Beyond Vibe-Coding: Scaling AI with GitHub Spec Kit](https://www.markbeacom.com/blog/architecture/genai/github-spec-kit) - Architectural perspective on scaling AI-assisted development beyond ad-hoc prompting using structured specifications.
- [Diving Into Spec-Driven Development With GitHub Spec Kit](https://developer.microsoft.com/blog/spec-driven-development-spec-kit) - Deep dive into Spec Kit components, slash commands, constitution document, and how the toolkit establishes version control for architectural thinking.
- [GitHub Open Sources Kit for Spec-Driven AI Development](https://visualstudiomagazine.com/articles/2025/09/03/github-open-sources-kit-for-spec-driven-ai-development.aspx) - News coverage of the open-source release reporting on rapid adoption with 16,000+ stars in the first week.
- [Inside Spec-Driven Development: What GitHub's Spec Kit Makes Possible](https://www.epam.com/insights/ai/blogs/inside-spec-driven-development-what-githubspec-kit-makes-possible-for-ai-engineering) - Enterprise perspective on how spec-driven development solves cracks in code-first workflows by using living specifications.
- [Putting Spec Kit Through Its Paces](https://blog.scottlogic.com/2025/11/26/putting-spec-kit-through-its-paces-radical-idea-or-reinvented-waterfall.html) - Critical evaluation asking whether the spec-driven development approach represents genuine innovation or a return to waterfall methodology.
- [Spec-Driven AI Coding with GitHub's Spec Kit](https://www.infoworld.com/article/4062524/spec-driven-ai-coding-with-githubs-spec-kit.html) - Hands-on coverage demonstrating practical use of Spec Kit within VS Code and GitHub Copilot for real projects.
- [Spec-Driven Development (Technology Radar)](https://www.thoughtworks.com/en-us/radar/techniques/spec-driven-development) - ThoughtWorks Technology Radar placement of spec-driven development at the Assess ring as an emerging AI-assisted engineering practice.
- [Spec-Driven Development from Code to Contract](https://arxiv.org/abs/2602.00180) - Academic paper presenting a comprehensive framework for spec-driven development with three levels of specification rigor.
- [Spec-Driven Development with AI](https://github.blog/ai-and-ml/generative-ai/spec-driven-development-with-ai-get-started-with-a-new-open-source-toolkit/) - Official launch announcement introducing Spec Kit, the four-phase SDD workflow, and the philosophy of treating coding agents as literal-minded pair programmers.
- [Spec-Driven Development: A First Review](https://dev.to/danielsogl/spec-driven-development-sdd-a-initial-review-2llp) - Early developer review exploring how spec-driven development addresses quality issues in AI-assisted coding workflows.
- [Spec-Driven Development: The Waterfall Strikes Back](https://marmelab.com/blog/2025/11/12/spec-driven-development-waterfall-strikes-back.html) - Provocative analysis arguing the methodology echoes the Waterfall era while acknowledging its structural benefits for AI coding.
- [Spec-Kit Taming AI-Coding Chaos](https://virtuslab.com/blog/ai/spec-kit-tames-ai-coding-chaos/) - Engineering analysis of how spec-driven development shifts the work balance to roughly 50% planning, 20% coding, and 30% verification.
- [Unpacking Spec-Driven Development](https://www.thoughtworks.com/en-us/insights/blog/agile-engineering-practices/spec-driven-development-unpacking-2025-new-engineering-practices) - Companion analysis to the Technology Radar entry expanding on scope, granularity, and adoption potential of the methodology.
- [Using Spec-Driven Development for Brownfield Code Exploration](https://www.epam.com/insights/ai/blogs/using-spec-kit-for-brownfield-codebase) - Practical guide to applying spec-driven development for legacy system analysis and modernization.
- [What's The Deal With GitHub Spec Kit](https://den.dev/blog/github-spec-kit/) - In-depth analysis from the project's principal product manager covering the eight-step workflow, practical caveats, and a real-world demo.
