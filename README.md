## Tools

- [adr-tools](https://github.com/npryce/adr-tools) - Command-line tools for creating and managing Architecture Decision Records as lightweight Markdown documents (no longer maintained).
- [Ajv](https://github.com/ajv-validator/ajv) - The fastest JSON Schema validator for Node.js and browser, supporting multiple specification drafts.
- [AsyncAPI Generator](https://github.com/asyncapi/generator) - Generates code, documentation, and configurations from AsyncAPI specification files for event-driven architectures.
- [Buf](https://github.com/bufbuild/buf) - Modern CLI for linting, formatting, and detecting breaking changes in Protocol Buffer specifications.
- [Log4brains](https://github.com/thomvaill/log4brains) - Docs-as-code knowledge base that logs Architecture Decision Records and publishes them as a searchable static website (no longer maintained).
- [OpenAPI Generator](https://github.com/OpenAPITools/openapi-generator) - Generates API client libraries, server stubs, and documentation from OpenAPI Specification files.
- [Prism](https://github.com/stoplightio/prism) - Turns any OpenAPI or Postman Collection file into a mock API server with request validation and contract testing.
- [Redocly CLI](https://github.com/Redocly/redocly-cli) - All-in-one command-line tool for linting, validating, bundling, and generating documentation from API specifications.
- [Spectral](https://github.com/stoplightio/spectral) - Flexible JSON and YAML linter for creating automated style guides, with built-in support for OpenAPI and AsyncAPI.
- [Swagger Editor](https://github.com/swagger-api/swagger-editor) - Browser-based editor for designing, defining, and documenting APIs using the OpenAPI Specification.

## Tutorials

- [AsyncAPI Getting Started](https://www.asyncapi.com/docs/tutorials/getting-started) - Official tutorial series covering how to define event-driven API interfaces using the AsyncAPI specification.
- [Learn OpenAPI](https://learn.openapis.org) - Official OpenAPI Initiative learning portal with documentation, examples, and guidance for writing specifications.
- [OpenAPI Tutorial](https://idratherbewriting.com/learnapidoc/openapi_tutorial.html) - Comprehensive hands-on tutorial walking through each major object in an OpenAPI specification.
- [Using ADRs](https://docs.aws.amazon.com/prescriptive-guidance/latest/architectural-decision-records/welcome.html) - Enterprise-grade guide from AWS covering the complete Architecture Decision Record lifecycle and best practices.

## Articles

- [Seriously, Write Your API Spec First](https://www.readysetcloud.io/blog/allen.helton/seriously-write-your-spec-first/) - Practical argument for why teams should always write their API specification before any implementation.
- [Spec-Driven Development with AI](https://github.blog/ai-and-ml/generative-ai/spec-driven-development-with-ai-get-started-with-a-new-open-source-toolkit/) - Official introduction to GitHub Spec Kit and the rationale for structured spec-driven workflows with AI coding agents.
- [Spec-First API Development for Speed and Sanity](https://www.atlassian.com/blog/atlassian-engineering/spec-first-api-development) - Case study from Atlassian engineering on transitioning to spec-first API design for faster development cycles.
- [Understanding Spec-Driven Development Tools](https://martinfowler.com/articles/exploring-gen-ai/sdd-3-tools.html) - Critical evaluation of Kiro, GitHub Spec Kit, and Tessl examining what spec-driven development means in practice.

## Example Projects

- [Architecture Decision Record](https://github.com/joelparkerhenderson/architecture-decision-record) - Comprehensive collection of ADR examples, templates, and guidance for software planning and technical leadership.
- [MADR](https://github.com/adr/madr) - Lean and structured Markdown Architectural Decision Records template used widely in open-source and enterprise projects.
- [OpenAPI Specification](https://github.com/OAI/OpenAPI-Specification) - The canonical repository for the most widely adopted API specification standard, maintained by the OpenAPI Initiative.
- [Rust RFCs](https://github.com/rust-lang/rfcs) - One of the most mature examples of specification-first open-source governance, where every major language feature starts as an RFC.
- [Spec Kit](https://github.com/github/spec-kit) - Open-source toolkit for spec-driven development providing templates, prompts, and a structured workflow for AI-assisted engineering.
